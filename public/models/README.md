# 3D Model Dosyaları

Bu klasöre aşağıdaki dosyayı ekleyin:

## tree-spruce.glb
- Detaylı ladin ağacı (spruce tree) modeli
- Mashy 6 tarzı yüksek detaylı ağaç
- Format: GLB (binary GLTF)
- Önerilen boyut: Optimize edilmiş, 5MB altında
- Dosya yolu: `/public/models/tree-spruce.glb`

## Model Özellikleri
- Koyu kahverengi gövde (trunk)
- Yeşil iğne yapraklı dallar (foliage)
- Katmanlı konik dallar (layered conical branches)
- Detaylı yapı (Mashy 6 tarzı)
- Gerçekçi gölgeler ve ışıklandırma

## Model Oluşturma
3D ağaç modeli oluşturmak için:
- Blender (ücretsiz) - detaylı ladin ağacı modeli oluşturun
- Veya online araçlar: Spline, Sketchfab
- GLB formatına export edin
- Gövde: Koyu kahverengi (#3d2817)
- Dallar: Yeşil tonları (koyu yeşilden açık yeşile)

## Fallback
GLB model bulunamazsa, otomatik olarak detaylı procedural ladin ağacı oluşturulacaktır (Mashy 6 tarzı detaylı).
