Güvenlik ve Gizlilik

Tamamen Güvenli

Bu araç sadece GitHub API'sini kullanarak arama yapar. Hiçbir dosya indirmez, çalıştırmaz veya sisteminize erişmez.

Sadece Okuma

Tüm işlemler salt okunur modda gerçekleşir. Sisteminizde herhangi bir değişiklik yapılmaz.

Web Tabanlı Güvenlik

Uygulama tarayıcınızda çalışır, bilgisayarınıza hiçbir yazılım yüklenmez. Kişisel verileriniz toplanmaz veya saklanmaz.

API Güvenliği

GitHub'ın resmi ve güvenli API'si kullanılır. Tüm bağlantılar şifrelenmiş HTTPS üzerinden yapılır.

Nasıl Çalışır?

01

Akıllı Arama İsteği

Arama teriminiz GitHub API'sine gönderilir. Sistem isim, açıklama, konular ve README dosyalarında arama yapar.

02

Çoklu Dil Desteği

Türkçe, İngilizce veya başka dillerde arama yapabilirsiniz. Sistem tüm dillerdeki repoları bulur.

03

Görüntüleme

Sonuçlar ekranda gösterilir, hiçbir şey indirilmez. İşlevsellik bazlı arama ile daha alakalı sonuçlar alırsınız.

Önemli: Virüslü veya zararlı içerik aramanız durumunda bile sisteminiz güvendedir. Araç sadece bilgi gösterir, hiçbir dosya indirmez veya çalıştırmaz.
